## Laboratorio de Datos

Este repositorio incluye una **serie de recursos y ejercicios prácticos orientados a divulgar diferentes formas de reutilización de datos abiertos**. A partir de sus características, hemos diferenciado dos tipos de recursos: 

- **[Visualizaciones](Visualizaciones/)** donde encontrarás recursos que describen los pasos necesarios para implementar visualizaciones de datos abiertos desarrolladas con diferentes herramientas. 
- **[Data Science](Data%20Science/)**, que dispone de ejercicios rácticos orientados a describir tareas relacionadas con la ciencia de datos, como el aprendizaje automático o el procesamiento del lenguaje natural, entre otros.
